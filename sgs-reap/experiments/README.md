# 实验工作区

这个目录只保存当前库状态、运行中间记录和可审计结果。

```text
library.jsonl          当前可变库；正式重建前为空
library_cold.jsonl     已停用引理；正式重建前为空
results/               自检报告和未来正式报告
runs/                  逐题、逐轮中间记录，默认不提交
```

历史开发报告和旧引理库已经从当前工作区移除。它们使用旧数据、旧统计口径或不完整运行，容易被
误认为正式结论；如需追溯，请查看 Git 历史和 `docs/history/`。

正式结果必须：

- 文件名包含运行模式、题目规模和冻结库哈希；
- 记录模型、提示词、采样参数、Lean 环境和 token；
- 区分输入拒绝、模型失败和服务故障；
- 能关联到对应的冻结引理库快照；
- 不覆盖已有正式报告。
