# experiments

实验目录保存库状态、冻结快照、逐轮运行记录和正式报告。

## 三组对照

1. A：真实需求 + SGS Guide 选择；
2. B：真实需求 + reuse/cost 选择；
3. C：随机等量伪需求 + reuse/cost 选择。

A/B 共用候选池，仅比较选择判据；B/C 保持选择、预算和执行配置相同，仅比较需求信号。

## 目录语义

- `results/`：当前仪器产生的开发或正式报告；正式文件名必须带 mode、规模和快照哈希。
- `runs/`：逐轮中间记录，默认不入库。
- `archive/`：退役仪器和历史报告，只用于追溯。
- `library.jsonl`：当前开发期可变库；在三态迁移完成前不是正式活动库。
- `library_cold.jsonl`：历史冷存。
- 后续正式评测只接受不可变 `LibrarySnapshot`，不直接读取“当前可变库”。
