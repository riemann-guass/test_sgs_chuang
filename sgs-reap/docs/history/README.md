# 历史材料

这里保存项目从早期 SGS 复现设想演变为 LeanReuse 的过程记录，包括阶段日志、旧方案和迁移
说明。它们用于回答“为什么现在这样设计”，不是当前使用手册。

阅读当前项目请按以下顺序：

1. 仓库根目录 `README.md`；
2. `docs/architecture.md`；
3. `sgs-reap/docs/data-protocol.md`；
4. `sgs-reap/scripts/README.md`。

历史文档中的 P0/P1/G1/G3、旧 C1/C2、旧数据规模、旧脚本名和旧实验数字均已退役，除非
当前文档明确引用，否则不得用于运行项目或支撑正式结论。
