# Phase 36：建立第一版可还原基线

日期：2026-09-30

## 目标

把工程整理完成后的当前状态保存为第一个正式版本，使后续修改可以与它比较，并能在不破坏
当前开发记录的情况下还原。

## 完成内容

- 将工程版本定为 `1.0.0`，由根目录 `VERSION` 保存；
- 新增 `CHANGELOG.md`，明确第一版的能力边界和未完成实验；
- 新增 `docs/versioning.md`，说明版本号、标签、比较和安全还原方法；
- 在 README、项目状态和协作约束中登记版本基线；
- 排除并清理 LaTeX 编译临时文件，避免把本机构建产物纳入版本；
- 为对应提交创建不可移动的带说明标签 `v1.0.0`。

## 验收

- 正向检查：纯 Python 项目自检全部通过；
- 正向检查：`VERSION`、更新记录和还原说明一致指向 `1.0.0`；
- 正向检查：`v1.0.0` 标签与版本提交指向同一提交；
- 失败样例：查询不存在的 `v1.0.1` 标签必须失败，确认没有误建未来版本。

本阶段没有调用模型，没有正式建库，也没有运行开发集或最终测试集。
