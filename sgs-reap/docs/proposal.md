## 一句话定位

**保留 SGS 的三角色结构、循环形状与防退化思想，只换两样东西**：

1. **Guide 的判据**：从"LLM 猜"换成"形式化、面向工作负载的测量 G"；
2. **"变强"的载体**：从权重更新换成**引理库 + prompt 记忆注入**（不做任何梯度训练）。

前提事实（P0 之前四个前置对话已核实）：SGS 的训练期自博弈**搬不进 tactic**——tactic 活在单次
elaboration 内，没有跨 episode 的模型更新。能做且值得做的是把三角色搬到**推理期循环**。

## 与 SGS 的对应关系

| SGS（训练期） | SG-Lean（推理期） | 处理方式 |
|---|---|---|
| Conjecturer：条件化在未解目标上出训练题 | 条件化在**未解目标 + 轨迹里的需求状态 + 已入库引理范例**上出**引理** | 角色保留，输入扩展（N1） |
| Solver：整篇生成 + 验证 | 同，且**额外产出轨迹**（子目标状态流）供需求挖掘 | 角色保留，增加产出 |
| Guide：LLM judge 给 review | **形式化价值 G** = 硬门 × 软分 | 职责保留，实现替换（N2/N3） |
| 奖励 `review × (1 − solve_rate)` | `硬门 × 软分`，其中 `(1 − solve_rate)` 以"可证硬门 + 难度带"的形式保留 | 思想保留，形式化 |
| 权重更新 | **库更新（子模贪心）+ prompt 记忆注入** | 载体替换 |
| HARD 选择（solve_rate ∈ (0, 0.5]） | `solve_rate > 0` 进候选池；难度带作为可调超参 | 保留 |
| 三角色 / 循环形状 / 防退化 | **全部保留（不变量）** | — |

**不变量**：不做梯度训练；三角色与"生成—求解—评估—反馈"的环不许拆成直线；防退化（不重复出题、
不奖励投机）必须仍由 G 承担。

## G 的定义（核心）

```
G(τ) = 硬门 × 软分

硬门（布尔，任一为假即淘汰）                        成本：零或极低
  ├─ 非平凡：simp / aesop / decide 在预算 B 内解不出
  ├─ 新颖  ：不 α-等价于已有引理/目标，且库检索未命中
  └─ 可证  ：solve_rate(τ) > 0（Solver 采样 k 次）

软分（连续，用于排序与子模选择）                    成本：只需证明文本与库
  ├─ 压缩收益 Δlen(τ)：用了该引理后证明变短（搜索展开数 / token 数两个度量）
  └─ 覆盖收益 cover(S) = |{w ∈ W : w 能被 S 帮助证明}|   ← 并集形式 → 单调子模 → 贪心 (1−1/e)

可选分量（时间允许时）
  └─ 多样性：形式化描述子（Mathlib 模块 / 命题形状 / 证明长度桶 / 主要 tactic）建档案，每格留最优
```

硬门三项各自替代 rubric 里的哪一句：非平凡 ← "平凡给低分"；新颖 ← "与目标等价给 0 分"；
可证 ← `(1 − solve_rate)`。**三件都由 Lean 算出，不含任何 LLM 判断。**

## 三个组成模块

### N1 需求驱动的条件化

从**真实证明轨迹**里聚合反复出现的子目标状态，作为 Conjecturer 的额外输入：

```
d(g) = freq(g) × cost(g)
  freq 必须分层统计：成功轨迹 s(g) / 失败轨迹 b(g)
  判为需求还要 g 出现在 ≥ m 个不同目标上（过滤 MCTS 死路的伪影）
```

类比来源：编译器的公共子表达式消除——引理不是"发明"出来的，而是**被真实需求逼出来的**，
因此天然相关、天然可复用。这条轴上目前没有工作。

### N2 引理库 = 工作负载驱动的子模最大化（本项目核心创新点）

给定工作负载 W，用贪心选出 top-B 引理入库：

```
cover(S) = |{w ∈ W : ∃ s ∈ S, s 能帮助证明 w}|     单调子模 → 贪心 (1−1/e) 近似
```

类比来源：数据库的**物化视图选择**（view selection problem）——目标集=查询负载、引理=视图、证明=查询。
此前 ATP 侧只做到 difflib 字符串去重（LEGO-Prover 的实测结论是"抽出的引理大多不可复用"，
本模块正是把这件事变成一个**有近似保证的优化问题**）。

### N3 压缩收益当价值

概念前身是 Colton 等人 2000 年的 compression-interestingness：好引理让证明变短。
形式化且廉价：全库证明总长度（总 tactic 数 / 总 token 数）的下降量。这是一个**全局**目标，
与"帮当前这个目标"是两件不同的事。

## 两条可证伪主张

| 编号 | 主张 | 对照 | 判据 |
|---|---|---|---|
| **H1** | 需求驱动的条件化（N1）比只条件化在"未解目标"上，产生**库命中率更高**的引理 | 同预算、同 Solver，只改 Conjecturer 的输入 | 库命中率 / 被依赖率 |
| **H2** | 以压缩 + 覆盖为价值的形式化选择（N2/N3），在同预算下比 SGS 的 **LLM Guide 打分**产生在 held-out 上更有用的库 | **P0 的 `/guide` + GuideClient + rubric 原样保留作对照组** | held-out 上的 pass@k |

P0 已经量化了 H2 要改进的对象：**Guide 占一次标定的 98% completion token**（20 次调用
45104 tokens），而它的分数与候选可用性几乎不相关。

## 与既有工作的划界

| 工作 | 它占了什么 | 我们为什么不重复 |
|---|---|---|
| **SGS**（arXiv 2604.20209） | LLM 判断信号 → 生成器迭代（Lean/Mathlib 规模） | 我们把判断信号换成形式化测量 |
| **STP**（arXiv 2502.00212） | "出题器在 barely provable 上迭代"的骨架（≈ SGS 去掉 Guide） | 同轴已被占，不碰"让题更好"这条轴 |
| **MINIMO**（2024） | 形式化信号 → 生成器迭代，但只在玩具公理域（受限解码需要小语法集） | 我们用 LLM 生成 + Lean 事后判定替代 by-construction 合法性，因此能上 Mathlib 规模 |
| **Bourbaki**（2025） | 形式化信号 → **搜索内 value**（单次搜索，无课程、无生成器迭代） | 我们做的是跨轮次的库与课程，不碰搜索内 value |
| **LEGO-Prover**（2023） | 抽取引理 + difflib 去重 + LLM 演化 | 它止步于字符串去重，我们做覆盖度子模选择；且它实测的"引理大多不可复用"正是我们的问题陈述 |
| **MathlibLemma**（arXiv 2602.02561） | folklore 引理挖掘流水线 | 它是"发现—形式化—证明"的生产线，我们是"选什么留什么"的优化问题 |
| 理论论文（arXiv 2606.01861） | 命名了"非平凡但无用"问题，给出图 + 多样性的解法 | 我们不与它正面竞争；多样性在我们这里降级为可选分量 |

一句话：**没人占的交叉是 Lean/Mathlib 规模 + 生成器跨轮迭代 + 形式化信号 + 库的选择与记忆管理。**

## 闸门与降级预案

| 闸门 | 问题 | 不过怎么办 |
|---|---|---|
| **G1** | Solver 到底能不能证出东西（50–100 条初等引理的 solve_rate 分布） | 换模型（本地 REAL-Prover 7B / Kimina）/ 退到 Nat 域 / 把整篇生成降级为骨架 + 搜索 |
| **G2** | 重复子目标是否常见，能否与死路伪影区分 | N1 降级，主线只留 N2 + N3 |
| **G3** | cover 是否有便宜且仍具子模性的代理 | 放弃 (1−1/e) 近似保证，改述为启发式选择 |
| **G4** | H1/H2 是否成立 | **负结果同样算通过**（测量型研究），但不得无数据声明 |

闸门是停机点：不过就按上表降级，**不擅自换主线**。

## 约束

- 预算 ~8000 元，禁止商业数据集 / 商业证明引擎 / 专用硬件；自建薄代理接 OpenAI 兼容后端（P0 已实现）。
- 不训练权重；"课程变好"只能用固定 held-out 上的 pass@k 证明，更新对象是 prompt 记忆注入。
- 所有实验用公开基准；复用开源代码需注明来源与版本（P0 已锁 reap `1477439`）。
