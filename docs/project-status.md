# LeanReuse 当前状态

更新日期：2026-09-30。

当前稳定工程基线：`v1.0.0`。它保存的是正式实验前的可运行框架；还原和比较方法见
[版本管理说明](versioning.md)。

## 已经完成

- 单题证明和批量评测入口；
- 模型生成、Lean 批量验证和逐题结果落盘；
- 候选引理生成、硬性检查、试用、晋升和淘汰；
- 只发布已验证引理的冻结库；
- miniF2F 数据的确定性 122/61/61 划分；
- 防止开发集、最终测试集或改名副本进入建库流程；
- 相关性优先的库检索；
- 证明项常量级的真实引用统计；
- 95 条纯 Python 检查和 5 条 Lean 集成检查。

## 当前没有什么

- 没有基于新数据划分建立的正式引理库；
- 没有可用于论文结论的正式正确率；
- 没有运行最终测试集；
- 没有模型训练、微调或 GPU 依赖。

因此，仓库当前展示的是一套已经打通并经过轻量验证的实验框架，而不是已经完成的实验结论。

## 下一阶段

用户已决定暂缓实验。恢复实验后建议按以下顺序进行：

1. 在 122 道建库题和 61 道复用测量题上建立正式库；
2. 在 61 道开发题上检查参数、成本和有库/无库差异；
3. 冻结代码、模型配置、提示词和引理库；
4. 运行预先约定的对照实验；
5. 最后只运行一次 244 道最终测试题。

任何旧开发数字都不能替代上述流程。
